# Source review — 2026-10-13

The Odds API public terms:
https://the-odds-api.com/terms-and-conditions.html
Allow indefinite retention, research/analytics and model training; prohibit
redistributing/reselling standalone raw data. Keep archives and databases private.
Public terms are reviewed; any account-specific contractual changes remain
unknown. Source HTML is retained locally under data/source-review.

Official documentation:
https://the-odds-api.com/liveapi/guides/v4/
Historical snapshots support dated EPL fixtures/1X2 odds. Twelve sampled weekly
snapshots cover 100 distinct fixtures at T-24h in this demonstration. Coverage is
sampled and can be stale. Historical fixtures are provider observations, not a
complete official fixture archive. The scores endpoint only covers recent days,
so it cannot recover the 2024 historical score publication record.

Football-Data current page:
https://www.football-data.co.uk/data.php
States use is for private individuals only, not commercial or data training
products using automated bots/scrapers/AI. No result CSV has been downloaded or
imported. Earlier suggestions to use it are superseded by this source review.
A separate permission agreement would be required for this automated pipeline.

Remaining dependency: a licensed historical EPL results/statistics export with
provider identifiers and documented publication/update times. Unknown source
publication times must be represented as observed-only, not backdated to kickoff.
No source subscription has been bought or upgraded. Squad data is optional when
reliable and timestamped; missing fields remain explicitly missing.

Gate 1 / full Phase 1 acceptance remains incomplete. Recovered odds alone are
insufficient to claim results-based features or calibrated-model readiness.
